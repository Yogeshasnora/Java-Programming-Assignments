Java Assignment Solutions

Contains 15 assignment folders and 49 Java programs.
Each task is a separate .java file.
Class names restart for each assignment as requested:
Task 1 -> program_01, Task 2 -> program_02, etc.

Compile and run one task at a time from its assignment folder:
    javac program_01.java
    java program_01

Do not compile all assignment folders together in one command because class names
are intentionally reused across assignments.
